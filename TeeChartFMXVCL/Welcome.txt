 The Docs folder contains:
 -------------------------

 TeeChart.hlp: Component Library reference

 TeeChart.chm: HTML format Library reference, Tutorials and User Guide

 TeeUser.hlp: Runtime Editor help (source included)

 The sub folder 'RAD Studio' for those IDE versions that support HTML Help 
 v2, contains files to support F1 context sensitive help from the IDE.


 The Demo project located in the Examples folder (Tee9New),
 includes more than 575 forms showing full TeeChart 
 capabilities.

 The QuickReport folder includes the source code of
 the "TQRChart" component.

 With these sources you can re-compile TeeChart for any 
 QuickReport version.

 See the "QuickReport\Install.pdf" file for complete details.

 The "Examples\VCL for the Web" folder includes the source code
 of the "TeeChart for Intraweb" component and an example project
 showing its usage.

 Keep visiting our web site and the private sections for
 upgrades, new announcements, examples, technical information and
 Frequently Asked Questions.
